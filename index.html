本周实验任务

本周目标：完成 Ubuntu 实验环境配置，熟悉 Linux 的目录、终端命令和权限管理，为后续 ROS 2 实验准备可用环境。

  1. 根据自己的电脑选择一种虚拟机方案，按照本页实验手册安装 Ubuntu 并完成软件源配置。不需要同时安装多种虚拟机。修改磁盘或虚拟化设置前，请先备份重要文件。
  2. 完成 Linux 基本操作、目录结构、常用命令和权限管理练习。请保存关键命令与运行结果；遇到问题时，记录报错画面、系统与软件版本以及已经完成的步骤。
  3. 实验中使用自己的普通账户和 sudo 执行需要管理员权限的操作，不要启用 root 登录，也不要修改实验室公共设备的账户密码。第 7 份手册中“root 密码每次重启随机生成”的说法不准确，请以 Ubuntu 权限说明 为准。

提前完成实验的同学：请进入第一次论文选读页面，从本期推荐中选择感兴趣的论文开始阅读。可以阅读一篇，也可以阅读多篇。

第一周作业：完成一份论文阅读报告。论文数量不限，可以围绕一篇论文深入分析，也可以比较多篇论文。报告至少应说明论文研究的问题、主要方法、实验或结果、你的理解，以及它与机器人课程内容的联系。不要只翻译摘要。

请使用 Overleaf 和 LaTeX 编写报告并导出 PDF。通过这次作业开始熟悉文档结构、章节标题、数学公式、表格、图片与题注、交叉引用及参考文献的编辑方法。提交方式与截止时间以课堂通知为准。
