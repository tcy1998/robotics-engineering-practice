实验课 1任务

实验目标：完成 Ubuntu 实验环境配置，掌握 Linux 的基本操作，为后续 ROS2 实验准备可用环境。

  1. 根据自己的电脑选择一种虚拟机方案，安装 Ubuntu 并完成软件源配置。不需要同时安装多种虚拟机；修改磁盘或虚拟化设置前，请先备份重要文件。
  2. 完成目录结构、常用终端命令和权限管理练习，保存关键命令与运行结果。遇到问题时，记录报错画面、系统与软件版本以及已经完成的步骤。
  3. 使用普通账户和 sudo 执行需要管理员权限的操作，不要启用 root 登录，也不要修改实验室公共设备的账户密码。

提前完成实验的同学：请进入第一次论文选读页面开始阅读。

第一周作业：选择一篇或多篇论文完成阅读报告，使用 Overleaf 和 LaTeX 编写并导出 PDF。报告应说明研究问题、主要方法、实验结果和个人理解，不要只翻译摘要。提交方式与截止时间以课堂通知为准。

Docker 手册

核心：介绍与安装、hello-world、容器使用、硬件与数据交互、Docker 中安装 ROS。

拓展：镜像发布、容器日常管理与 Docker 仓库。

ROS2 手册

核心：安装、命令行、工作空间、功能包、节点、话题、服务与动作。

拓展：参数、DDS、Launch、TF2、URDF、Gazebo、Rviz 与 RQT。

实验课 2任务

实验目标：理解容器化开发环境的基本思路，完成 ROS2 工作空间与基础通信实验。

  1. Docker 基础：完成 Docker 安装与 hello-world 测试，练习镜像、容器和目录映射等基本操作，并尝试在容器中运行 ROS2 环境。
  2. ROS2 基础：创建工作空间和功能包，运行节点、话题发布/订阅以及服务或动作示例；使用相应的 ros2 命令检查节点和通信状态。
  3. 实验记录：保留关键命令、运行结果和必要截图。遇到问题时记录完整报错、ROS2 版本、运行环境及已经尝试的解决方法。

拓展任务：完成较快的同学可以继续练习 Launch、TF2、URDF、Rviz 或 RQT，也可以进入第一次论文选读页面继续阅读论文。
