实验前须知

同学们，请在实验课前完成以下准备：在自己的电脑上安装一种虚拟机软件，并根据对应手册安装 Ubuntu。系统镜像、Ubuntu 版本和软件版本以课堂通知为准，不需要同时安装多种虚拟机。携带电脑和电源适配器，确保能够进入 Ubuntu 桌面并正常使用终端。

请提前备份电脑中的重要文件。修改磁盘分区、虚拟化设置或网络配置前，先确认操作对象，不要在不理解命令作用时直接执行。遇到安装问题时，请记录报错画面、所用版本以及已经完成的步骤，实验课上据此排查。

Ubuntu 默认锁定 root 密码。实验中使用自己的账户和 sudo 完成需要管理员权限的操作，不要启用 root 登录，也不要修改实验室公共设备的账户密码。第 7 份手册中“root 密码每次重启随机生成”的说法不准确，请以 Ubuntu 权限说明 为准。

实验过程中请保存关键命令、输出结果和问题处理过程。提交实验报告时，用 LaTeX 编写并导出 PDF，报告应说明实验环境、完成步骤、结果分析和遇到的问题；截图只保留能够支持结论的内容。
