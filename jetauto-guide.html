一、开机前与启动完成的判断

  1. 把机器人放在平整地面，远离桌边，检查车轮、主控、雷达与线缆。若带机械臂，避免开机时机械臂被压住或堵转。
  2. 电池电压低于 10 V 或扩展板蜂鸣器发出低电量报警时，先充电。使用随套件提供的充电器；充电时关闭机器人，不要边充电边运行，也不要把充电器插到 Jetson Nano 主板的 DC 供电口。
  3. 按下电源开关后，扩展板蓝色 LED1 闪烁只表示网络配置服务已开启。等蜂鸣器短鸣一声，再开始连接 ROS 系统。
  4. 出厂默认 AP 直连模式通常会出现以 HW 开头的热点。若 LED1 常亮，设备可能处于局域网模式；先确认当前模式，不要把示例局域网 IP 当成固定 IP。

多人在同一场地使用手柄时可能发生互串、误控。真机速度实验应保留充足空地，并准备可随时发送零速度指令的第二个终端。

二、怎么连接机器人

先认清主控与连接工具

主控图形桌面命令行官方出厂账号示例
Jetson NanoNoMachineMobaXterm / SSHjetauto / hiwonder
Jetson Orin Nano / Orin NXNoMachineMobaXterm / SSHubuntu / ubuntu
Raspberry Pi 5VNCMobaXterm / SSHpi / raspberrypi

上表是官方文档给出的出厂示例。实验室若更改过账号、密码或镜像，请以设备管理员提供的信息为准。Jetson Orin Nano / Orin NX 用 NoMachine 前，官方要求连接外接屏幕或虚拟显示器。台式电脑若需连接机器人 5G Wi-Fi，应准备支持 5G 频段的无线网卡。

方式 A：AP 直连，课堂优先使用

  1. 电脑连接机器人生成的 HW… Wi-Fi；官方默认热点密码为 hiwonder。该模式不能通过机器人热点访问外网。
  2. Jetson 主控打开 NoMachine，连接 192.168.149.1；树莓派 5 打开 VNC，连接同一个地址。只需要命令行时，可用 MobaXterm 新建 SSH 会话并填入该地址。
  3. 按主控型号输入账号和密码。连接成功后，先确认看到的是机器人系统桌面或 SSH 提示符，再继续操作。

方式 B：STA 局域网，适合同时需要联网

  1. 手机先连实验室 Wi-Fi。打开 WonderAi，选对 JetAuto / JetAuto Pro 型号，在“+”中选择“局域网模式”，输入该 Wi-Fi 的密码。
  2. 按 APP 提示临时连接机器人的 HW… 热点，等待机器人接入局域网。官方文档中 LED1 常亮对应局域网模式。
  3. 长按 APP 内的机器人图标，查看实际分配的 IP。让电脑连接同一局域网，再把这个实际 IP填入 NoMachine、VNC 或 SSH。官方示例中的 192.168.11.134 不是固定地址。
  4. 需要切回 AP 直连模式时，可按官方说明长按扩展板 KEY1，直到蓝灯重新闪烁。切换网络后原远程会话可能断开，应使用新模式的地址重连。

方式 C：USB 固定 IP，供 Jetson 主控选用

官方还介绍了 USB 网络连接：Jetson Nano 使用 Micro-USB，Jetson Orin Nano 使用 Type-C，配置好远程 NDIS 网络设备后使用 192.168.55.1。这一方法不适用于树莓派 5；第一次上课建议先用 AP 直连。

三、进入正确的 ROS2 环境

  • Jetson Nano：桌面上分别有 ROS1 和 ROS2 终端入口。本次底盘实验必须打开 ROS2 终端；如果命令或功能包找不到，先检查是否误开了 ROS1 终端。
  • Jetson Orin Nano / Orin NX：官方说明桌面只有 ROS2 终端。
  • Raspberry Pi 5：优先使用桌面上带机器人 ROS2 环境的终端，不要把系统任务栏里的普通终端误当成课程终端。

进入终端后，先运行 ros2 node list 与 ros2 topic list。接着查看 LAB 05 实验步骤，根据实机实际话题名启动底盘控制和观测数据。不同主控与镜像版本可能把工作空间放在不同位置；本页不要求重新安装 ROS2 或改写系统配置。

厂商文档说明整机出厂前已经完成 IMU 与运动参数标定。普通实验只观察数据与低速控制；只有设备出现明显直行或转向偏差时，才在指导教师确认后进行标定。

四、连接失败时先查这几项

现象先检查
找不到 HW… 热点确认已等待蜂鸣器短鸣；观察 LED1。常亮可能是局域网模式，蓝灯闪烁才对应出厂 AP 模式。若无法确定状态，请联系指导教师。
NoMachine / VNC 连不上核对主控型号、连接工具和网络模式；AP 用 192.168.149.1，局域网用 APP 显示的实际 IP。Orin 设备还应检查外接屏幕或虚拟显示器。
能登录但 ROS2 命令报错确认打开的是 ROS2 终端；Jetson Nano 同时有 ROS1、ROS2 环境。再检查课程功能包是否存在于当前镜像。
机器人仍在运动不要只按 Ctrl+C；在另一个 ROS2 终端向当前速度控制话题发送各分量为零的 Twist，目视确认停车。
